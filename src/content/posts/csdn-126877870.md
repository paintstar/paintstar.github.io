[E题链接](https://ac.nowcoder.com/acm/contest/40676/E)

这题要我们计算给定序列中连续子序列满足每种颜色是偶数的个数是多少。  
有一个突破口就是颜色的总数最多只有21种，可以想到用二进制来表示每种颜色的状态，221 也就是2e6多一点完全可以接受。这样就可以用0和1来表示每种颜色的状态。  
然后就是处理连续子序列问题，我们可以发现，我们从第一个数字开始，每次异或更新颜色的状态（0变成1,1变成0），如果中间经过了连续的相同的数字，得到的二进制数将和原来去掉这一段（这一段是符合题目要求的）相同。比如说我用3位二进制数表示三种颜色的状态。刚开始是`0 0 0`，输入的序列是`1 1 2 2 0`，第一次遇到`1` 变成`0 1 0` ，再遇到1就又变成了`0 0 0`，我们用一个map存储一下每个二进制的个数，如果变成了相同的二进制数那么就加上它。

## <a id="AC_7"></a>AC代码：

```cpp
#include<bits/stdc++.h>
using namespace std;
#define endl "\n"
map<int, int>mp;
int main()
{
	ios::sync_with_stdio(false); cin.tie(0); cout.tie(0);
	int n;
	cin >> n;
	int t = 0;
	mp[t]++;
	int ans = 0;
	for (int i = 1; i <= n; i++)
	{
		int x;
		cin >> x;
		t ^= (1 << x); //1<<x 找到该颜色对应二进制数中的哪一个位置
		ans += mp[t];// 以之前的相同的二进制数开始到当前数都是一个满足条件的序列
		++mp[t];
	}
	cout << ans << endl;
	return 0;
}
```

[I题链接](https://ac.nowcoder.com/acm/contest/9266/I)  
这题要我们找规律啊，刚开始没看懂题目，以为只是字母会表示十六进制数，之后问了下别人都表示十六进制数，所有规律是从右上到左下对角线不断增加。这里就可以用到图论的一个技巧就是对角线元素的x和y（第x行第y列）相加是相等的。对于x+y<n ，即最长的那根对角线左边的元素，我们呢很容易找到第一个对角线的值然后再+x。对于x+y>=n 的元素来说，我们就找到反对角线，然后减去n与x之间的差。

## <a id="AC_36"></a>AC代码：

```cpp
#include<bits/stdc++.h>
using namespace std;
#define ll long long

int main()
{
    ios::sync_with_stdio(false); cin.tie(0); cout.tie(0);
    int n, x, y;
    cin >> n >> x >> y;
    ll ans = 0;
    if (x + y < n)
    {
        ans += (ll)(x + y) * (ll)(x + y + 1) / 2;
        // 这里是用了等差数列求和求出第一行 也就是对角线第一个元素的值
        ans += x;
    } 
    else
    {
        ans += (ll)n * n - 1;
        ll k = x + y - n+1;
        k = n - 1 - k;
        ans -= (k * (k + 1)) / 2;
        // 这里先求了最后一个值然后也是用了等差数列的性质求出来了最后一行
        // 也就是反对角线的第一个值
        ans -= n - 1 - x;
    }

    cout << ans << endl;
    return 0;
}
```
