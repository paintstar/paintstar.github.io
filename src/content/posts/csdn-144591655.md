## <a id="_0"></a>前言

目前阶段cangjie经常更新，这就导致我们可能会需要经常在不同的版本之间切换。  
在参加训练营时从张老师那学到了如何使用 vscode 的配置文件来快速进行cangjie版本的切换。  
推荐一下张老师的兴趣组 [SIGCANGJIE / 仓颉兴趣组](https://gitcode.com/sigcangjie)

这里以 windows 下，配置目前仓颉最新版本 0.57.3 为例

## <a id="_6"></a>实际操作

### <a id="cangjie____vscode_7"></a>下载cangjie 版本 和 对应的 vscode插件

没有权限的可以先申请一下 [仓颉通用版本获取与安装配置](https://gitcode.com/Cangjie/CangjieCommunity/blob/main/%E9%80%9A%E7%94%A8%E7%89%88%E6%9C%AC%E8%8E%B7%E5%8F%96%E4%B8%8E%E5%AE%89%E8%A3%85%E9%85%8D%E7%BD%AE.pdf)  
![image.png](/images/posts/csdn-144591655/image-01.png)

这里建议如果是下载压缩包的话可以使用 7ZIP 进行解压，使用其他的可能会无法解压成功。  
解压完毕之后如下图所示  
![image.png](/images/posts/csdn-144591655/image-02.png)

![image.png](/images/posts/csdn-144591655/image-03.png)

### <a id="vscode__18"></a>vscode 操作

左下角设置 -> 配置文件 -> 配置文件  
![image.png](/images/posts/csdn-144591655/image-04.png)

新建配置文件 cangjie5703，注意这里设置要用当前的，不然会覆盖默认的设置  
![在这里插入图片描述](/images/posts/csdn-144591655/image-05.png)

右下角点击创建，然后我们在配置文件中切换到 cangjie5703  
![image.png](/images/posts/csdn-144591655/image-06.png)

在拓展中点击从vsix安装  
![image.png](/images/posts/csdn-144591655/image-07.png)

选择之前下载的 vscode 插件  
![image.png](/images/posts/csdn-144591655/image-08.png)

然后进入插件设置，将 cangjie sdk path 修改为之前下载的cangjie 0.57.3的路径  
![在这里插入图片描述](/images/posts/csdn-144591655/image-09.png)

最后ctrl + ~ （打开终端快捷键）杀死原来的终端，打开终端然后点击那个小垃圾桶标志的，然后全部删除。之后重新开启一个终端即可。  
![image.png](/images/posts/csdn-144591655/image-10.png)

然后我们查看一下版本，看一下有没有问题  
![image.png](/images/posts/csdn-144591655/image-11.png)

运行一下也没有问题，这里需要注意以下这只是在vscode中的终端是可以使用的，如果你用电脑本身自带的powershell或者cmd查看cangjie版本，查到的肯定是你 path 中设置的那一个版本。  
![在这里插入图片描述](/images/posts/csdn-144591655/image-12.png)
