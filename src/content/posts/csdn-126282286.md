## <a id="pta___0"></a>pta - 说反话-加强版

给定一句英语，要求你编写程序，将句中所有单词的顺序颠倒输出。

## <a id="_3"></a>输入格式：

测试输入包含一个测试用例，在一行内给出总长度不超过500 000的字符串。字符串由若干单词和若干空格组成，其中单词是由英文字母（大小写有区分）组成的字符串，单词之间用若干个空格分开。

## <a id="_5"></a>输出格式：

每个测试用例的输出占一行，输出倒序后的句子，并且保证单词间只有1个空格。

## <a id="_7"></a>输入样例：

```cpp
Hello World   Here I Come
```

## <a id="_11"></a>输出样例：

```cpp
Come I Here World Hello
```


> 这题很有意思，问题就在于空格的处理，可能开头有空格，行末有空格，所有都是空格，麻烦的做法有很多，我想了一会儿才想出来这种相对简单的做法

## <a id="AC_26"></a>AC代码：

```cpp
#include<bits/stdc++.h>
using namespace std;
string v[500005];
int main()
{
	int cnt = 0;
	string s;
	getline(cin, s);
	for (int i = 0; i < s.size(); i++)
	{
		if (s[i] != ' ') v[cnt] += s[i];
		else
		{
			if (i<s.size()-1&&s[i + 1] != ' '&&v[cnt]!="") cnt++; //这里很关键
			// 保证了上一个cnt中一定有值，避免了开头空格错误的情况
		}
	}
	for (int i = cnt; i >= 0; i--)
	{
		cout << v[i];
		if (i > 0) cout << ' ';
	}
	return 0;
}
```
