输入2个字符串S1和S2，要求删除字符串S1中出现的所有子串S2，即结果字符串中不能包含S2。

## <a id="_1"></a>输入格式：

输入在2行中分别给出不超过80个字符长度的、以回车结束的2个非空字符串，对应S1和S2。

## <a id="_3"></a>输出格式：

在一行中输出删除字符串S1中出现的所有子串S2后的结果字符串。

## <a id="_5"></a>输入样例：

```cpp
Tomcat is a male ccatat
cat
```

## <a id="_11"></a>输出样例：

```cpp
Tom is a male 
```

## <a id="AC_27"></a>AC代码：

```cpp
#include<bits/stdc++.h>
using namespace std;

int main()
{
	string s;
	getline(cin, s);
	string s2;
	getline(cin, s2);
	int cnt = 100;
	while (cnt--)  //我删你个100次，怎么说
	{
		int temp = s.find(s2); // temp 返回找到的子串的第一个字符的下标
		if (temp != s.npos)
		{
			s.erase(temp, s2.size());  // 从下标开始删除子串个数目的字符
		}
	}
	cout << s << endl;
	return 0;
}
// 写题解的原因：加深对string 中find 函数和erase函数的 印象
```
