### <a id="_34"></a>为什么要配置环境变量？

其实配不配置环境变量都是可以的，但是如果不配置环境变量，每次运行mysql命令都需要进入到bin目录中去，而如果配置了环境变量，我们在cmd中的任意位置都可以使用mysql命令，  
例如：  
![在这里插入图片描述](/images/posts/csdn-131604170/image-10.png)  
并且配置了环境变量也方便我们查找mysql 的安装路径

-   因为我的电脑已经安装过了mysql，所以接下来的mysql路径和我上面配置path的路径不同，大家仅供参考。

### <a id="mysql_42"></a>初始化mysql数据库

1.  接着在mysql安装主目录下，创建一个记事本，将下面内容写进去

-   **下面空着的basedir和datadir路径是需要自己填写的！！**

```sql
[mysqld]
# 设置3306端口
port=3306
# 设置mysql的安装目录   ----主目录路径--（如：C:/mysql-8.0.23-winx64）
basedir=
# 设置mysql数据库的数据的存放目录  --文件路径data文件夹,自动创建（（如：C:/mysql-8.0.23-winx64/data））
datadir=
# 允许最大连接数
max_connections=200
# 允许连接失败的次数。
max_connect_errors=10
# 服务端使用的字符集默认为utf8mb4
character-set-server=utf8mb4
# 创建新表时将使用的默认存储引擎
default-storage-engine=INNODB
# 默认使用“mysql_native_password”插件认证
#mysql_native_password
default_authentication_plugin=mysql_native_password
[mysql]
# 设置mysql客户端默认字符集
default-character-set=utf8mb4
[client]
# 设置mysql客户端连接服务端时默认使用的端口
port=3306
default-character-set=utf8mb4
```

保存，然后将记事本改为my.ini。

-   如果是本地一键下载也会有这个my.ini，不过是自动创建的，有兴趣的可以去找找，主要内容都大差不差，就是路径可能不在主目录下。

2.  然后打开cmd，进入mysql的bin目录（一路使用cd命令进入就行了）  
    ![在这里插入图片描述](/images/posts/csdn-131604170/image-11.png)  
    输入`mysqld --initialize`命令，成功之后即可在mysql的安装主目录下看到data文件夹，其实是因为你之前设置了路径，如果你不是设置在了主目录下，也就不会在主目录下看到data文件夹  
    ![在这里插入图片描述](/images/posts/csdn-131604170/image-12.png)  
    （说明：若在安装过程中提示系统某些dll文件缺失，可在百度下载微软公司Visual C++的运行库vc\_redist.x64.exe，官网下载地址：https://support.microsoft.com/en-us/topic/the-latest-supported-visual-c-downloads-2647da03-1eea-4433-9aff-95f26a218cc0）
    
3.  初始化成功后，输入`mysqld --install` 命令，完成MySQL安装  
    ![在这里插入图片描述](/images/posts/csdn-131604170/image-13.png)
    
4.  安装成功后，输入`net start mysql` 命令开启mysql服务  
    ![在这里插入图片描述](/images/posts/csdn-131604170/image-14.png)  
    使用root用户登陆，在命令窗口输出：（初始化root密码可在data目录下查看.err文件，查找root@localhost:–后面的密码，注意不要复制空格）`mysql -uroot -p`登陆成功后则表示安装成功了。  
    ![在这里插入图片描述](/images/posts/csdn-131604170/image-15.png)  
    修改root账户密码。  
    root登陆成功后，先使用命令：`alter user ‘root’@‘localhost’ identified by ‘新密码’` ，再输入`use mysql` 使用mysql，注意这里新密码要打引号
    
5.  愉快地使用mysql！！
