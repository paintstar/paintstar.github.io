设要将$\frac{n}{a}$ 向上取整 ，如要令$\frac{3}{4}$=1  
只需要$\frac{n+a-1}{a}$即可  
解释：  
一般方法，判断n/a是否有余数，如果有余数则+1，如果没有余数则不变。例如

```cpp
int temp=n/a;
if(n%a!=0) temp++; 
```

如果`n%a == 0`,则`n==ka`，所以$\frac{n+a-1}{a}$ == $\frac{(k+1)a-1}{a}$==k;  
如果`n%a != 0`,则`n ==ka+t (t>=1&&t<a)`,那么$\frac{n+a-1}{a}$ ==$\frac{(k+1)a+t-1}{a}$ == k+1。(t-1一定是一个小于a的正数)

## <a id="_11"></a>所以上述代码可改写为：

```cpp
int temp=(n-a+1)/a;
```
